# Portfolio Website Development Log

## Approach

Before creating my website, I considered what I wanted to showcase in my portfolio. My main focus was games programming, but I was unsure whether I had enough projects to fill the site. I reviewed my previous game design work and found some 3D models to include alongside my programming projects. I also considered adding animation work. I planned the website sections, including a skills section and links to my Itch.io and GitHub accounts. <br>
I wanted the website to present my work clearly and make relevant information easy for potential employers to find. I also considered how the layout and colour scheme would reflect my interests in games development while keeping the site professional and readable.

## Result

Several changes were made during development. I added an education section displaying my qualifications, grades and the skills I gained during my studies. This was one of the final additions, inspired by presentations of other students' websites. <br>
I decided against including my animation work, as I felt this would make my portfolio too generalised and less focused on games programming. Instead, I kept my programming projects as the main focus, with my 3D models positioned below them to showcase additional skills without distracting from my intended career path.<br>
Accessibility was another consideration. I added links to my GitHub and Itch.io accounts, individual project repositories, and pages where visitors could play or view my projects. These links allow employers to examine my work and access the relevant code. I also planned to include Sketchfab links for my 3D models, but temporarily removed them because I could not access my account. I intend to restore these links once the issue is resolved. <br>
Choosing a colour scheme took longer than expected. I tested at least ten different combinations before settling on the current design. I wanted to maintain a dark theme suitable for a games programming portfolio while ensuring the text remained readable. I expect to continue refining the colours as I develop the website further.

## Reflection

Creating this portfolio was a valuable learning experience. It encouraged me to consider how I present my skills and projects to potential employers, rather than focusing solely on writing code. Finding a suitable design required several adjustments, particularly when choosing colours that maintained a dark theme without affecting readability. <br>
Setting up Doxygen documentation alongside GitHub Actions was the most technical part of the project. Once configured, the workflow automatically generates live documentation from my C++ code whenever I push changes to GitHub. This allows potential employers to review my programming work without requiring me to update separate documentation pages manually. The process also gave me practical experience with continuous integration and continuous delivery (CI/CD), which are relevant skills within the games industry. <br>
Deciding which work to include was equally important. Removing my animation work helped maintain a clear focus on games programming, while my 3D models demonstrated additional artistic skills. This approach helped me present a more targeted portfolio for programming roles. In future, I plan to restore the Sketchfab links and continue adding new projects and code as I develop my programming skills. I also intend to review the website regularly to ensure the content reflects my latest experience.
