# Instructions to build the docs locally
1. Download Doxygen and run "doxygen --version" in Powershell to verify that it is installed.
2. Open powershell in the src folder within the repository.
3. Run "doxygen Doxyfile".
4. Navigate to docs/html and open the index.html file
